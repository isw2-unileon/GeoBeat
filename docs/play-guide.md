# Modes

You can switch modes using the **"Mode selection"** tab in the right-hand panel or **"Menu -> Mode Selection"** in the mobile menu.

---

## Daily Mode

- In the right-side panel, there is a list showing all possible genres. The user can type to filter the search and narrow it down to specific genres.
- Below the genre selection field, there is a button used to confirm the selection.

## Inverse Mode

- To make a guess, it is necessary to click on a country (it will be highlighted in blue) and then press the **Guess** button.
- You can see the target song on the right-hand panel

---

## Time Trial Mode

- This mode works the same as Daily Mode, with the difference that there is no limit on the number of attempts.
- At the end of the mode, the user's score is recorded in a leaderboard where other scores can be viewed.

---

## Guesses and Hints

- Wrong guesses are shown in **yellow**, and correct guesses are shown in **green**.
- In Daily Mode, hovering over the left square allows the user to see the guess and a hint when the guess is wrong.
- In Inverse Mode, only the guess is displayed when hovering.
- Time Trial Mode does not include hints or previous guesses.
